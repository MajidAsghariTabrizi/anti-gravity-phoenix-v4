## What this blog is not

- It is not financial advice.
- It is not a PnL report. Phoenix does not claim realized profit.
- It is not a marketing surface. Posts are written for engineers investigating the underlying design questions.
- It is not an outreach tool. Posts are not syndicated to external platforms on the project's behalf.

When Phoenix has a verified live execution and reconciled realized net PnL, it will say so explicitly and link the evidence. Until then, every post preserves the `FULL_LIVE_NO_ALPHA` disclaimer.
